# Погодный контекст

## Источники

| Источник | Что даёт | Ограничения |
|---|---|---|
| Архив Open-Meteo (`archive-api.open-meteo.com/v1/archive`, модель `era5`) | Почасовые значения на дату эпизода по сетке 4×4 и центру области | ERA5: 0,25° (около 25 км), с 1940 г., обновление ежедневно с задержкой около 5 дней. Высотного ветра в этом API нет. |
| Текущая погода Open-Meteo (`api.open-meteo.com/v1/forecast`, `current=…`, модель `best_match`) | Текущие значения (15-минутные данные модели) и ветер на уровнях 850/700/500/300 гПа с геопотенциальной высотой | Только для сценария с сегодняшней датой. |
| Ручные условия | Значения, заданные пользователем | Не называются историческими. Пустое поле — «не задано». |

Переменные: `temperature_2m`, `precipitation`, `rain`, `snowfall`, `cloud_cover`, `wind_speed_10m`, `wind_direction_10m`, `wind_gusts_10m`, `wind_speed_100m`, `wind_direction_100m`, `weather_code` (подмножество WMO 4677). Скорость ветра запрашивается в м/с, время — UTC.

Реанализ — модельная оценка, а не наблюдение на месте. Разрешение модели показывается рядом с данными.

## Как проверены сведения

Сайт Open-Meteo и его API из среды сборки недоступны (сетевая политика). Документация, условия и лицензия прочитаны из исходного кода официального сайта: `github.com/open-meteo/open-meteo-website`, коммит `5cc7ca6` от 24.09.2026 (изменения условий отслеживаются в этом репозитории). Живые ответы API не проверялись; тесты используют синтетические ответы в документированном формате. Запросы выполняет браузер пользователя, поэтому у пользователя с доступом к сети погода загружается.

## Условия использования

Бесплатный API — только некоммерческое использование, меньше 10 000 вызовов в сутки, 5 000 в час, 600 в минуту; данные — CC BY 4.0 с указанием источника (подпись «Weather data by Open-Meteo.com (CC BY 4.0)» сохраняется в снимке). Коммерческое использование — по платной подписке. Если атлас используется в работе организации, проверьте, подпадает ли это под некоммерческое использование.

## Без сети

- Показывается причина: нет подключения, запрос заблокирован, ошибка сервера, лимит (HTTP 429), ошибка API, тайм-аут, дата вне архива.
- Предлагается сохранённый ранее снимок того же источника на ту же дату или ручные условия.
- Архивная погода не подменяется текущей, и наоборот. Проверка сценария сообщает об ошибке, если сохранённый снимок другого вида или другой даты.
- Отсутствующее значение показывается как «нет данных», а не 0.

## Снимок и повтор

Загруженный снимок сохраняется в сценарии вместе с адресом запроса, моделью, временем данных и временем получения. Запуск и повтор используют этот снимок, а не новый ответ API.

## Игровые эффекты

Реальная погода — исторический и визуальный контекст. Влияние на игру задают игровые пресеты:

| Пресет | Обнаружение | Время классификации | Болтанка | Ветер слоёв по умолчанию |
|---|---|---|---|---|
| Ясно | ×1 | ×1 | 0 | 0 |
| Ветрено | ×0,95 | ×1,1 | 1,5 град/с | 12 / 25 / 40 м/с с запада |
| Осадки | ×0,75 | ×1,35 | 0,8 град/с | 6 / 14 / 22 м/с |
| Гроза | ×0,6 | ×1,6 | 3 град/с | 16 / 28 / 38 м/с |
| Туман | ×0,85 | ×1,5 | 0 | 2 / 5 / 10 м/с |

Это игровые эффекты, а не физические поправки для какого-либо оружия.

Автовыбор пресета по центральной точке: код WMO 95–99 → «Гроза»; 45/48 → «Туман»; дождь, морось или снег при осадках ≥ 0,5 мм/ч → «Осадки»; ветер на 10 м ≥ 10 м/с или порывы ≥ 17 м/с → «Ветрено»; иначе «Ясно». Если значений нет, выбирается «Ясно» с пометкой «игровое допущение».

Ветер игровых слоёв (если включено «брать ветер из данных»):

| Слой | Откуда |
|---|---|
| 0–300 м | ветер на 100 м (или 10 м) из снимка |
| 300–4000 м | уровень 850 или 700 гПа текущей модели; для архива — пресет |
| выше 4000 м | уровень 500 или 300 гПа текущей модели; для архива — пресет |

Условия на высоте полёта из приземного ветра не выводятся.

## Анимация

Линии приземного ветра, дождь (наклон по ветру), снег, вспышки грозы, дымка тумана и сплошной облачности. Интерполяция между узлами сетки — только для отображения. Плотность частиц зависит от качества отображения; при системной настройке «уменьшить движение» анимация останавливается. На расчёт анимация не влияет.

Ventusky используется только как внешняя ссылка для сравнения: публичного API у него нет, архив доступен только на его сайте, его данные в сценарий не попадают.
