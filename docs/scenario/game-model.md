# Воздушная игровая модель

> Условная учебная модель. Не прогноз реальных боевых действий. Все классы, параметры, стороны и правила вымышлены.

Код: `src/game`. Модуль не импортирует справочник (`src/data/reference`) и историческую базу (`src/history`) — это проверяет тест. Сценарий (`src/scenario/setup.ts`) переводит свои данные в чистые игровые: плоские км, стороны, классы, погодные множители.

## Единицы

| Величина | Единица |
|---|---|
| Положение | км в плоской игровой системе (x — восток, y — север); для исторической карты — равнопромежуточная проекция от центра ветки, сфера 6371 км |
| Высота | м |
| Скорость | м/с |
| Время | с эпизода; шаг модели — 0,5 с |
| Топливо | секунды полёта |
| Запас | условные единицы (у.е.) |

## Цикл

Появление → перемещение → обнаружение → классификация → игровое решение → взаимодействие → завершение и запись результата.

Состояния самолёта: подготовка → полёт → выполнение сценарного действия (патрулирование, разведка, перехват в зоне, отделение нагрузки) → возвращение → завершение (посадка или выход из эпизода).

## Движение

- Плавный разгон и торможение с ограничением ускорения класса.
- Ограниченная скорость поворота (град/с); курс поворачивается к цели не больше чем на предел за шаг.
- Набор и снижение высоты с ограничением скорости.
- Ветер игрового слоя складывается с воздушной скоростью; автопилот разворачивает нос против ветра (треугольник скоростей), чтобы путь шёл по маршруту. В карточке видны курс и путь, воздушная и путевая скорость.
- Болтанка — случайное отклонение курса по игровому пресету погоды.
- Снаряды следуют к текущему положению цели. Это игровой приём, а не алгоритм наведения.
- Синус и косинус считаются собственными многочленами, поэтому журнал одинаков во всех браузерах.

## Правила решений

П-1…П-10 перенесены из прежней учебной симуляции без изменения смысла. П-7 расширено: самолёт или беспилотник стороны без игрового конфликта только сопровождается. Добавлены П-11 (совместимость классов), П-12 (ресурс и задержка), П-13 (погодный пресет), П-14 (ручное управление), П-15 (игровое топливо), П-16 (нагрузка носителя), П-17 (истребитель в зоне), П-18 (малая высота). Полный текст — `src/game/rules.ts` и «Почему?» в журнале.

## Воспроизводимость

- Фиксированный шаг; интерфейс лишь решает, сколько шагов досчитать к кадру. Если расчёт не успевает, показ замедляется, а шаги не пропускаются.
- Все жребии — из одного генератора Mulberry32 с зерном, в фиксированном порядке.
- Команды хранятся с отметкой времени и применяются ровно один раз на шаге с `t ≥ отметки`.
- Контрольные снимки состояния сохраняются с выбранной частотой; перемотка назад восстанавливает ближайший снимок и досчитывает с теми же командами.
- Отпечаток (FNV-1a журнала и итоговых положений) совпадает при повторе с тем же начальным состоянием, зерном, настройками, погодным снимком и командами.

## Что намеренно не моделируется

Реальные позиции подразделений, поиск уязвимостей обороны, оптимизация атак, расчёт огневых решений и поражения, реальные алгоритмы наведения, калибровка по результатам реальных событий, достоверная баллистика.
