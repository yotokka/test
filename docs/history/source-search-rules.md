# Правила поиска и проверки источников (исторический режим)

## Порядок работы с фактом

1. **Вопрос.** Сформулировать проверяемый вопрос: «С какой даты в наборе X территория Y закодирована как часть Z?», «Когда договор D вступил в силу для сторон A и B?».
2. **Первоисточник.** Найти документ (договор, правовой акт, документ ООН, архив) или документированный академический набор данных.
3. **Открыть сам документ.** Найти подтверждающий раздел, страницу, запись. Сниппет поисковой системы, Wikipedia и Wikidata — только указатели, где искать.
4. **Сверить охват.** Утверждение относится именно к этой территории, этому субъекту и этому периоду? Экспортная версия, другая модификация, другое государство с похожим названием — частые ошибки.
5. **Спорный факт.** Найти независимое подтверждение или сохранить несколько атрибутированных версий (статус «источники расходятся»).
6. **Записать происхождение.** URL, название, издатель, дата публикации, дата доступа, точное место (файл, запись, поле, страница), версия набора, условия использования, примечания о противоречиях.
7. **Только после проверки** факт влияет на основное состояние исторического режима.

## Статусы

| Статус | Значение | Влияет на основное состояние |
|---|---|---|
| проверено по документу | документ открыт, место подтверждения записано | да |
| импортировано из документированного набора | запись взята из версии набора с документацией; файл получен и сверен по контрольной сумме | да |
| требует проверки | найдено, но первоисточник не открыт (например, только поисковая выдача) | нет; показывается только при включённом «Показывать требующее проверки» |
| источники расходятся | два источника дают разные даты или трактовки; обе версии хранятся | да, по правилу слоя: карта — даты CShapes, список государств — даты GW |

## Шаблоны поиска

- `[договор] entry into force [страна] site:un.org`
- `[организация] [страна] accession date official`
- `[государство] independence act [год] archive`
- `[изменение границы] treaty map historical`
- те же запросы на языке соответствующей страны.

Официальный источник подтверждает позицию своего государства, но не доказывает её всеобщее признание.

## Что было доступно при сборке 26.09.2026

Из среды сборки **не открывались**: icr.ethz.ch (CShapes), naturalearthdata.com, treaties.un.org, un.org, ucdp.uu.se, atopdata.org, correlatesofwar.org, ksgleditsch.com и официальные сайты государств. Поэтому:

- географические и событийные данные получены **только** из опубликованных авторами пакетов (CRAN через зеркало github.com/cran, npm), с проверкой MD5 по манифестам пакетов — статус «импортировано из документированного набора»;
- ни один факт не получил статус «проверено по документу»;
- договоры, известные только по поисковой выдаче (из справочного раздела), имеют статус «требует проверки» и не входят в основное состояние;
- членство в организациях, дипломатические отношения, смены официальных названий и флаги не заполнены — пробел показан в интерфейсе.

## Как добавить проверенный факт

1. Открыть документ и записать место подтверждения.
2. Добавить источник в `src/history/sources.ts` (с датой доступа и условиями).
3. Добавить событие с `verification: 'document-verified'`, `sources: [{ id, locator }]`, точностью даты (`day` / `month` / `year`) и `recordedAt` — датой добавления в базу (не датой события).
4. Запустить `npm test`: тесты проверят ссылки на субъекты и источники.
