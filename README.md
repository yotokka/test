# Атлас ракет и противовоздушной обороны

Русскоязычный учебный сайт: чем различаются типы ракет, почему открытые сведения о дальности противоречивы и как в общих чертах работает ПВО. Дизайн — мягкое ретро 1980-х: тёмный аналитический терминал.

> **Данные — демонстрационный набор.** При сборке (26.09.2026) прямой доступ к сайтам источников был закрыт сетевой политикой среды. Ссылки и значения взяты из поисковой выдачи, тексты первоисточников полностью не сверялись. Перед использованием откройте каждую ссылку и сверьте число вручную.

## Разделы

| Раздел | Что внутри |
|---|---|
| **Мир и сценарии** | Три связанных режима. **Историческое воспроизведение** — карта мира с 1 января 1970 г. по границам CShapes 2.0 (до 31.12.2019), время 1× … «1 год/сек», события, карточки, «Почему карта выглядит так?». **Редактирование сценария** — ветка альтернативной истории от выбранной даты: участники, изменения мира (удалить, объединить, сохранить субъект, отменить событие, допущение), правило «остановить» или «продолжать совместимые» события с объяснением пропусков, каталог игровых объектов, маршруты, нагрузка, погода, проверка. **Воспроизведение сценария** — воздушный эпизод в секундах и минутах: запуск, пауза, шаг, скорость ×0,25…×60, автопаузы, перемотка, повтор, продолжение новой веткой, немедленные команды, очередь действий, журнал с «Почему?». Испытательная сцена с вымышленными странами и 10 готовых учебных сценариев (5 новых и 5 перенесённых из прежней симуляции). |
| **Справочник** | 24 записи о ракетах (баллистические, крылатые, зенитные) из 10 стран; поиск и фильтры по стране, типу, периоду и наличию данных. **Каталог техники**: 44 семейства в 8 категориях (баллистические и крылатые ракеты, авиационные ракеты, зенитные системы, истребители, бомбардировщики и носители, разведчики и вспомогательные, беспилотники) — модификация, страна происхождения, эксплуатанты с периодами, раздельные «заказано / поставлено / в строю», таблица покрытия. Вкладки «ПВО: принципы» и «Соглашения и союзы». |
| **Сравнение** | Таблица, где заявления, результаты испытаний и независимые оценки стоят в разных строках, и график значений на логарифмической шкале. Есть готовые наборы для сравнения. |
| **Источники** | 38 публикаций: тип, дата публикации, дата и способ проверки, где используется. |
| **Методология и ограничения** | Заявление, испытание и оценка; модификации; дальность и эффективность; пределы открытых данных; разделение справочных и учебных данных. |

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # сборка в папку dist/
npm run preview    # просмотр собранной версии: http://localhost:4173
```

Для просмотра без сервера: `npm run build:single` соберёт весь сайт в один файл `dist-single/index.html` (скрипты, стили и шрифты встроены) — его можно открыть двойным щелчком.

Папка `dist/` — статический сайт. Его можно открыть на любом веб-сервере (nginx, IIS, GitHub Pages): маршрутизация работает через `#`, настраивать сервер не нужно.

## Исторический режим: данные и версии

| Слой | Источник | Версия | Покрытие |
|---|---|---|---|
| Границы, столицы, статус | CShapes 2.0, вариант Gleditsch & Ward, с зависимыми территориями | R-пакет cshapes 2.0 (CRAN, 2021-06-05), MD5 `e6ff3960…` | 1970-01-01 — 2019-12-31 |
| Список независимых государств | Gleditsch & Ward | R-пакет states 0.3.3 (2025-08-25) | до 2025-08-25 |
| Вооружённые конфликты | UCDP ACD | 25.1 (подмножество peacesciencer 1.2.0) | до 2024-12-31 |
| Руководители | Archigos | 4.1 (подмножество peacesciencer 1.2.0) | до 2015-12-31 |
| Физическая подложка | Natural Earth 1:110m land | 4.1.0 (npm world-atlas 2.0.2) | современная, без политических границ |

Не заполнены (показаны как пробел): союзы ATOP/COW (условия не проверены), членство в организациях, дипломатические отношения, смены официальных названий, флаги, фактический контроль. Договоры из справочника — «требует проверки».

Обновить базу: `pip install pyreadr && npm run data:update` (подробности — `scripts/data/README.md`). Документы: `docs/history/` — правила поиска источников, картографическая методология, условия использования, таблица покрытия.

## Сценарии, игровая модель и погода

- Руководство по редактору и клавишам — `docs/scenario/editor-guide.md`; игровая модель — `docs/scenario/game-model.md`; погода — `docs/scenario/weather.md`; формат файла и миграции — `docs/scenario/format.md`; покрытие каталога — `docs/catalog/coverage.md` (пересобирается командой `npm run docs:coverage`).
- Погода: архив Open-Meteo (модель ERA5, с 1940 г., задержка около 5 дней), текущая погода Open-Meteo, ручные условия. Запросы выполняет браузер пользователя; снимок сохраняется в сценарии, повтор использует его. Без сети показывается причина и предлагаются сохранённый снимок или ручные условия. Бесплатный API Open-Meteo — только для некоммерческого использования, данные CC BY 4.0.
- Готовые сценарии открываются по адресу: `#/history?mode=edit&scn=demo:carrier` (также `manual`, `motion`, `gdr`, `stop`, `legacy-basics` и др.).

> **Условия использования.** Геометрия, производная от CShapes, распространяется на условиях CC BY-NC-SA 4.0 (некоммерческое использование, указание авторства, те же условия для производных). Объединённый набор не является свободным для любого использования — см. `docs/history/data-licenses.md`.

## Проверки

```bash
npm test           # модульные тесты: данные и каталог, исторический движок, игровая модель, ветки и редактор, погода (91 тест)
npm run test:e2e   # сквозные тесты в браузере, компьютер + телефон
```

Для `test:e2e` нужен Chromium для Playwright (`npx playwright install chromium`). Если браузер уже установлен в другом месте, укажите путь в `PW_CHROMIUM_PATH`.

Что проверяют тесты:

- у каждого числа и записи каталога есть источник, статус и даты; наличие в каталоге не означает наличия у страны; «заказано / поставлено / в строю» раздельны; фильтр по периоду различает разработку, испытание и службу;
- исторический режим: контрольные переходы (Германия, СССР, Чехословакия, Йемен, Южный Судан), воспроизводимость, перемотка, скорость, договоры, геометрия, пробелы;
- ветки: создание ветки не меняет историю; «сохранить», «удалить», «объединить» субъект и режим «остановить» с объяснением пропусков; новая ветка от момента эпизода не меняет исходный сценарий;
- редактор: отмена и повтор, дублирование, групповое изменение, журнал изменений, сохранение и загрузка без потери состояния, миграция старого формата, понятные ошибки схемы и несовместимых настроек;
- игровая модель: одинаковый журнал при разных скоростях показа и частотах кадров, однократное применение команды, восстановление после перемотки, отделение нагрузки от носителя, правила ПВО по игровым категориям, неотрицательные ресурсы, ограничения поворота, скорости и высоты, снос ветром, качество отображения не влияет на исход;
- погода: работа без API, причины ошибок, «нет данных» вместо нуля, архив и текущая погода не подменяют друг друга, высотный ветер не выводится из приземного;
- браузер: путь «дата → ветка → редактор → запуск → журнал → сохранение и восстановление», мышь, клавиатура, контекстное меню, автопауза и «Почему?», очередь действий, повтор, телефон без горизонтальной прокрутки.

## Ограничения

**Данные**
- Все значения сверены только по поисковой выдаче. Где атрибуция в выдаче была неоднозначной, это отмечено в примечании к значению.
- У С-75 и Patriot PAC-3 MSE дальность не приводится: надёжного числа с понятной атрибуцией не нашлось.
- Для большинства источников дата публикации не установлена и так и помечена.
- Набор систем неполный; «период» — укрупнённая классификация атласа.
- Статус договоров после дат, указанных в карточках, не проверялся (в том числе СНВ-III после февраля 2026 г.).

**Игровая модель**
- Плоская игровая система координат, фиксированный шаг 0,5 с, условные классы и вероятности. Кинематика и ветер — игровые, без претензии на достоверную аэродинамику и баллистику.
- Результаты показывают цепочку условий и роль правил, но не предсказывают исход реального столкновения.
- Намеренно нет реальных позиций подразделений, поиска уязвимостей обороны, оптимизации атак, расчётов поражения и реальных алгоритмов наведения. Сценарии со взаимодействиями — на вымышленной испытательной сцене.
