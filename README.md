# Атлас ракет и противовоздушной обороны

Русскоязычный учебный сайт: чем различаются типы ракет, почему открытые сведения о дальности противоречивы и как в общих чертах работает ПВО. Дизайн — мягкое ретро 1980-х: тёмный аналитический терминал.

> **Данные — демонстрационный набор.** При сборке (26.09.2026) прямой доступ к сайтам источников был закрыт сетевой политикой среды. Ссылки и значения взяты из поисковой выдачи, тексты первоисточников полностью не сверялись. Перед использованием откройте каждую ссылку и сверьте число вручную.

## Разделы

| Раздел | Что внутри |
|---|---|
| **Исторический мир** | Карта мира с 1 января 1970 г. по историческим границам CShapes 2.0 (до 31.12.2019). Непрерывное время: 1× (секунда за секунду), «1 день/сек», «1 месяц/сек», «1 год/сек»; вперёд и назад; шаги на день, месяц, год и к событию; остановка на ключевых событиях; закладки; дата в адресе. Слои: государства, зависимые территории, спорные участки со штриховкой и атрибуцией, столицы, стороны конфликтов. Карточка страны на дату, карточка события с точностью даты и источниками, шкала событий с фильтрами и журнал, кнопка «Почему карта выглядит так?». |
| **Справочник** | 24 записи о ракетах (баллистические, крылатые, зенитные) из 10 стран; поиск и фильтры по стране, типу, периоду и наличию данных. Отдельные вкладки: «ПВО: принципы» и «Соглашения и союзы» (8 документов с датами и источниками). |
| **Сравнение** | Таблица, где заявления, результаты испытаний и независимые оценки стоят в разных строках, и график значений на логарифмической шкале. Есть готовые наборы для сравнения. |
| **Учебная симуляция** | Вымышленная карта и страны, 5 сценариев, этапы «появление → обнаружение → классификация → решение → условный перехват». Кнопки «Запуск/пауза», «Шаг», «Сброс», «Повтор сценария», скорость 0,5–4×, шкала времени, журнал с номерами правил, настройки отношений. |
| **Источники** | 38 публикаций: тип, дата публикации, дата и способ проверки, где используется. |
| **Методология и ограничения** | Заявление, испытание и оценка; модификации; дальность и эффективность; пределы открытых данных; разделение справочных и учебных данных. |

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # сборка в папку dist/
npm run preview    # просмотр собранной версии: http://localhost:4173
```

Для просмотра без сервера: `npm run build:single` соберёт весь сайт в один файл `dist-single/index.html` (скрипты, стили и шрифты встроены) — его можно открыть двойным щелчком.

Папка `dist/` — статический сайт. Его можно открыть на любом веб-сервере (nginx, IIS, GitHub Pages): маршрутизация работает через `#`, настраивать сервер не нужно.

## Проверки

```bash
npm test           # модульные тесты: данные, учебная модель, исторический движок (47 тестов)
npm run test:e2e   # сквозные тесты в браузере, компьютер + телефон (40 тестов, 4 пропуска по условию)
```

Для `test:e2e` нужен Chromium для Playwright (`npx playwright install chromium`). Если браузер уже установлен в другом месте, укажите путь в `PW_CHROMIUM_PATH`.

Что проверяют тесты:

- у каждого числа есть источник, статус, дата публикации (или явное «не установлена») и дата проверки;
- если значений несколько, есть объяснение расхождения; если данных нет, это пояснено;
- одинаковые сценарий, зерно и настройки дают одинаковый журнал и отпечаток; другое зерно меняет ход;
- модуль симуляции не импортирует справочную базу, и наоборот; на страницах нет смешения названий;
- союз без соглашения о совместной обороне не ведёт к перехвату; конфликт без угрозы защищаемой территории — тоже;
- поиск, фильтры, сравнение, ссылки на источники, запуск/пауза/шаг/сброс/повтор, клавиатура, выдвижные панели на телефоне, отсутствие горизонтальной прокрутки страницы;
- исторический режим: объединение Германии, распад СССР, распад Чехословакии, объединение Йемена, независимость Южного Судана — до, в момент и после перехода; отсутствие государств до их появления; восстановление состояния при перемотке назад; одинаковый результат при разных скоростях; статус договора между подписанием и вступлением в силу; ссылки только на существующие субъекты; общие дуги соседей и линия перемены дат; сохранность островов; видимость пробелов и спорных участков.

### Как устроена симуляция

- Время дискретное (такты). Все случайные события используют один генератор Mulberry32 в фиксированном порядке, поэтому результат полностью определяется сценарием, зерном и настройками отношений.
- Скорость показа меняет только темп проигрывания уже рассчитанных тактов и на результат не влияет.
- «Отпечаток журнала» (FNV-1a) позволяет убедиться, что повторный прогон совпал.
- Решения принимаются по 10 учебным правилам (П-1…П-10). Номер правила показан в журнале рядом с событием.
- Пользователь не выбирает цели и траектории: они зафиксированы в сценарии.

### Как обновлять данные

1. Откройте ссылку источника и найдите формулировку.
2. В `src/data/reference/missiles.ts` замените у значения `check.method` на `'direct'` и поставьте новую дату проверки.
3. Дату публикации в `sources.ts` меняйте, только если установили её по самому материалу.
4. Запустите `npm test`.

## Ограничения

**Данные**
- Все значения сверены только по поисковой выдаче. Где атрибуция в выдаче была неоднозначной, это отмечено в примечании к значению.
- У С-75 и Patriot PAC-3 MSE дальность не приводится: надёжного числа с понятной атрибуцией не нашлось.
- Для большинства источников дата публикации не установлена и так и помечена.
- Набор систем неполный; «период» — укрупнённая классификация атласа.
- Статус договоров после дат, указанных в карточках, не проверялся (в том числе СНВ-III после февраля 2026 г.).

**Модель**
- Двумерная вымышленная карта, дискретное время, фиксированные учебные вероятности. Физика полёта, датчики, связь и реальные процедуры не моделируются.
- Результаты показывают неопределённость и роль правил, но не предсказывают исход реального столкновения.
- Намеренно нет позиций, зон реального покрытия, готовности подразделений, уязвимостей, расчётов эффективности, выбора реальных целей и реальных координат.
